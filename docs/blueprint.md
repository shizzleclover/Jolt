# **App Name**: Jolt

## Core Features:

- Image Upload: Users can upload images of their study material directly or using their device camera.
- Automatic Text Extraction: Automatically extract text from uploaded images using OCR and AI text analysis tools.
- AI-Powered Quiz Generation: Use AI to generate multiple-choice questions (3-10 questions) based on the extracted text content.
- Timed Quiz Mode: Provide a timed quiz mode, so users can practice recall under pressure.
- Score Review: Display the user's score, indicate correct and incorrect answers, and provide options to review.
- Local Quiz Storage: Save quiz sessions locally within the browser for future review and practice.
- PWA Implementation: Implement as a Progressive Web App (PWA) to enable installation on devices for offline access and a native app feel.
- Performance Tracking: Track user progress over time
- Flashcard Mode: Convert extracted content into flashcards instead of quizzes
- Voice-to-Quiz Input: Users can dictate text or record short passages instead of uploading images. The voice input is transcribed and used to generate quiz questions, making it useful for brainstorming, quick reviews, or accessibility purposes.
- Daily Quiz Challenges: Gamify studying with daily AI-generated quizzes
- Difficulty Levels: Users can choose between basic, intermediate, or advanced question generation. The AI adjusts complexity and depth based on the selected level.
- Quiz Sharing: Share quizzes with friends via link
- Multiplayer Mode: Multiplayer mode against friends through a shared link or friend code
- Smart Explanations: After each answer, users can see an AI-generated explanation of why it’s correct or wrong — helping build deeper understanding, not just test scores.
- Topic Mastery Tracking: Identify which topics users struggle with by tagging each quiz and response.
- Authentication: Authentication with firebase, username, email and password, OTP confirmation and forgot password
- Accessibility Features: Text-to-speech, high contrast, keyboard navigation.
- Concept Map Generator: Automatically create a visual concept map or summary from scanned material, helping visual learners connect ideas.
- Personalized Study Goals: Let users set weekly or monthly goals and track them with reminders and achievement progress.
- Spaced Repetition & Smart Reminders: Push users to revisit past material at optimal intervals based on what they got wrong

## Style Guidelines:

- Light peach (#FFF9F5) to provide a soft, inviting feel.
- Coral (#FF7E5F) to reflect energy and intelligence.
- Apricot (#FEB47B) to highlight interactive elements and calls to action
- 'Space Grotesk', a sans-serif font for headlines, lends a techy, up-to-date look.
- 'Inter', a sans-serif font with a modern look, is suitable for body text.
- Also incorporate Jakarta Sans
- Use flat design icons with rounded edges for a friendly, approachable feel.
- Maintain a clean and spacious layout, prioritizing ease of use and readability.
